👋 Welcome
This repository documents my journey from wet-lab biology to computational modeling through machine learning and deep learning. Rather than serving as a polished course, it is a living collection of notes, experiments, projects, and reflections that evolve alongside my understanding.
My long-term goal is to apply modern AI methods to biological research, particularly in bioinformatics, genomics, and healthcare.
> **It's a journey, not a race.** Keep learning, keep building.
📂 Repository Structure
```
├── Machine_Learning/        # Core ML concepts, algorithms, and notes
├── Deep_Learning/           # Neural networks, architectures, and DL projects
├── Computational_Biology/   # Where ML/DL meets biological data
├── LICENSE
└── README.md
```
Each folder has its own README going into more detail on what's inside and how it's organized.
📁 Machine_Learning — foundations, supervised & unsupervised learning, evaluation, feature engineering
📁 Deep_Learning — neural nets, CNNs, architectures, and hands-on DL builds
📁 Computational_Biology — applying ML/DL to biological questions: genomics, bioimaging, and beyond

💡 Learning Principles
Learn by Building — Theory sticks better when it's reinforced through code.
Understand Before Optimizing — Focus on why a method works before chasing performance.
Visualize Everything — Good visualizations often reveal patterns that metrics alone miss.
Experiment Fearlessly — Failed experiments are still valuable learning opportunities.
Read Research Papers — Stay connected to developments beyond tutorials.
Write Clean Code — Future-you is one of your collaborators.
🔬 Where This Is Headed
Long-term, this repository aims to bridge machine learning and biology through practical applications in bioinformatics, genomics, biomedical imaging, and healthcare AI. As the repository grows, so will the complexity of the projects and the biological questions they address.
